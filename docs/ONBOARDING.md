# Lab Onboarding (15 minutes)

## 1. Install (5 min)
Follow the README: upload the skill on claude.ai, or install the plugin in Claude Code.
Connect **alphaXiv** and **Consensus** (plus **Scholar Feed** if your account offers it).

## 2. First run (10 min)
Bring one real need you have this week: a course assignment, a project decision, or a baseline to compare against.

Say: *"I need a paper for ..."* and answer the short questions it asks.

Check three things in the Fit Report:
- Does the **Need Spec** say what you actually want? If not, correct it. This is the most important step.
- Does each ✓ point to a real place in the paper (section or table)? Open one and check.
- Do the **near-misses** make sense? They show what the tool understood about your need.

## 3. Give the rating
Answer the 1 to 5 question at the end and add the row to the lab log.

## Good habits
- Always read the top pick yourself before citing it. The tool narrows the search; it does not replace reading.
- If it says "no good fit", believe it and loosen one must-have, rather than forcing a weak paper.
- It will not write graded text. Use it to understand, plan, and critique.

## What it is not (yet)
- Not a systematic review tool. A `review` skill for snowballing and gap-finding is planned for thesis students.
- Not connected to paywalled libraries. It works best on arXiv and open-access papers.
